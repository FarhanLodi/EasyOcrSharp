PaddleOCRNet 100-image OCR stress-test dataset
=================================================
100 synthetic PNG images covering:
- plain text
- multi-column layouts
- tables
- forms
- seals/stamps
- receipts/invoices
- low-quality images
- rotated/perspective-like documents
- dense mixed layouts
- handwriting-like text
- numbers/codes

Files are numbered 001-100 and include the category in the filename.
These are synthetic benchmark images intended for OCR pipeline testing.
